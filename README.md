# Mega Hub Plus

New from-scratch, Windows, controller-first PC launcher (C# + Avalonia). Separate from the Mega Hub fork and MegaHub. No code copied from either.

## Run it (on Windows, with the .NET 8 SDK)
    cd src
    dotnet run

Keys for now: Left/Right move, S or F2 opens Settings, Esc leaves Settings, F11 fullscreen, Enter picks a look at first start.

## Three looks (pick at first start, switch in Settings)
1. Console Row (PS5-style)
2. Blades (Xbox 360-style)
3. Wide Home (big wide featured tile + tall tiles)

Tile shape is a Settings option: wide 16:9, short 3:4, tall poster 2:3.

Concept images (from ChatGPT) are in docs/concepts. Sample game names are placeholder tiles only.
